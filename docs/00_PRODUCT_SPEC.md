# 00. 제품 요구사항

## 1. 제품 정의

PC TV Mirror는 Windows 10/11 PC의 화면과 시스템 소리를 동일 Wi-Fi의 Android TV 또는 Google TV로 저지연 전송하는 앱이다. Windows 앱은 송신자이고 TV 앱은 수신자다.

## 2. 주요 사용자 흐름

1. 사용자가 Android TV에서 수신 앱을 실행한다.
2. TV 앱이 로컬 네트워크에 자신의 수신 서비스를 광고한다.
3. Windows 앱이 TV를 자동 검색한다.
4. 최초 연결에서는 TV에 6자리 PIN이 표시된다.
5. PC에서 PIN을 입력해 기기를 신뢰 기기로 저장한다.
6. 이후에는 TV 선택과 연결 버튼 한 번으로 미러링을 시작한다.
7. TV가 첫 프레임을 표시하면 선택적으로 PC 프라이버시 화면을 활성화한다.
8. 사용자가 종료하거나 연결이 끊기면 화면과 오디오를 원상복구한다.

## 3. 필수 기능

### 화면

- 전체 모니터 전송
- 다중 모니터 선택
- 특정 앱 창 전송
- 화면 맞춤: Fit, Fill, Stretch, 1:1
- 마우스 커서 포함 여부
- 기본 1080p30, 고화질 1080p60
- 네트워크에 따른 비트레이트 조정

### 오디오

- PC 시스템 소리 TV 재생
- TV에서만 재생
- PC와 TV 모두 재생
- 화면만 전송
- TV 볼륨 조정
- A/V sync 보정
- 연결 종료 후 Windows 오디오 설정 자동 복구

### 연결

- 같은 Wi-Fi 자동 검색
- IP 직접 입력 보조 연결
- PIN 페어링
- 신뢰 기기 저장
- 자동 재연결
- 연결 품질 표시
- AP Isolation 감지 또는 안내

### 프라이버시

- TV에는 정상 화면, PC에는 검은 화면
- 캡처에서 제외되는 네이티브 검은 오버레이
- 전역 긴급 해제 단축키
- 장애 시 자동 해제
- 미러링 중 안내 문구 표시 옵션

### Windows 앱

- 시스템 트레이 실행
- Windows 로그인 시 자동 시작 옵션
- 최근 TV
- 빠른 연결
- 기본/고급 설정 분리
- 연결 로그와 진단 정보

### Android TV 앱

- Google TV/Android TV 홈 화면 런처
- 리모컨 방향키, 확인, 뒤로 버튼 완전 지원
- 연결 대기 화면과 PIN
- 전체 화면 영상 출력
- 하단 미러링 컨트롤
- 앱 재실행 후 신뢰 PC 표시

## 4. 첫 출시에서 제외

- 인터넷을 통한 외부 원격 스트리밍
- DRM 및 캡처 보호 콘텐츠 우회
- PC 원격 키보드·마우스 제어
- 모바일 송신 앱
- 여러 TV 동시 전송
- 4K60 필수 지원
- 녹화 및 방송 송출

## 5. 품질 목표

| 항목 | MVP | 출시 목표 |
|---|---:|---:|
| 해상도 | 720p30 | 1080p60 |
| 평균 LAN 지연 | 250ms 이하 | 120ms 이하 목표 |
| 오디오 | 스테레오 | Opus 48kHz 스테레오 |
| 재연결 | 수동 | 자동 재연결 |
| 크래시 복구 | 기본 | 화면·오디오 완전 복구 |
| TV 지원 | 개발 기기 1종 | 주요 Android TV 4종 이상 |

지연 목표는 하드웨어, 공유기, TV 디코더에 따라 달라질 수 있으므로 UI에서는 절대값을 보장하지 않는다.

## 6. 성공 기준

- 일반 사용자가 기술 설정 없이 3번 이내 조작으로 연결할 수 있다.
- TV 전용 오디오 종료 후 PC 소리가 원래 장치로 돌아온다.
- 프라이버시 스크린 중 네트워크를 끊어도 PC 화면이 자동 복구된다.
- TV 앱은 리모컨만으로 모든 기능을 사용할 수 있다.
- 30분 연속 미러링에서 앱이 종료되거나 메모리 사용량이 지속 증가하지 않는다.
