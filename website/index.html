Questions, answered

시작하기 전에
궁금한 점이 있나요?

인터넷 연결이 꼭 필요한가요?+

Sender와 Receiver를 연결하려면 PC와 TV가 같은 로컬 네트워크에 있어야 합니다. 기본 미러링 경로는 로컬 네트워크 중심으로 동작합니다.

어떤 화면을 TV로 보낼 수 있나요?+

Windows Sender에서 전체 화면 또는 미러링할 창을 선택하는 흐름을 지원합니다. 실제 제공 범위는 설치한 앱 버전에 따라 확인해 주세요.

내 화면이나 오디오가 저장되나요?+

현재 베타버젼은 미러링 콘텐츠를 자체 클라우드 서버에 저장하도록 설계되지 않았습니다. 콘텐츠는 미러링을 위해 실시간 처리됩니다.

연결이 되지 않으면 어떻게 하나요?+

두 기기가 같은 네트워크에 있는지 확인한 뒤 Receiver를 먼저 실행하고 Sender에서 다시 연결을 시도해 보세요.
