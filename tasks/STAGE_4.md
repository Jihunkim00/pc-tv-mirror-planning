# STAGE 4 — 프라이버시와 TV 전용 오디오

## Codex 시작 프롬프트

```text
이 단계는 안전 복구가 최우선이다.
프라이버시 화면이나 TV 전용 오디오를 추가할 때 실패 경로와 복구 테스트를 먼저 작성하라.
단순 Windows 음소거로 TV 전용 오디오를 구현하지 마라.
```

## 작업 순서

1. 복구 상태 저장 모델
2. TV first-frame-rendered ACK
3. 네이티브 검은 오버레이 HWND
4. 캡처 제외 적용
5. 전역 긴급 단축키
6. 연결 끊김 화면 복구
7. watchdog
8. 절전/사용자 전환 처리
9. 기존 Windows 오디오 장치 저장
10. 가상 오디오 장치 또는 라우팅 모듈
11. TV 전용 오디오
12. 종료 후 오디오 복구
13. 다음 실행 미복구 상태 복원
14. 강제 종료/TV 전원 차단 테스트

- [ ] TV 전용 오디오 정상
